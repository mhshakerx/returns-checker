# مدقق المرتجعات - Returns Checker

أداة تدقيق مرتجعات نقاط البيع تعمل بالكامل داخل المتصفح.

## المميزات بعد التعديل
1. **فلتر نسب الخصم في جدول المرتجعات**: 
   - بدون خصم / 10% / 20% / 30% / خصم آخر
   - موجود في شريط الأدوات فوق الجدول التفصيلي

2. **فلتر نسب الخصم في فواتير البيع المخالفة**:
   - فلتر منفصل فوق قسم "فواتير البيع المخالفة للسياسة"
   - يفلتر: 10% إضافي فوق عرض، 20%، 30%، خصم باقة، خصم نسبة آخر
   - يخفي/يظهر مخالفات اكتمال العرض وفواتير التوثيق حسب الاختيار

3. **إزالة بيانات تسجيل الدخول من الواجهة**:
   - لا يوجد أي نص يظهر اليوزر والباسورد في الصفحة
   - تسجيل الدخول لا يزال محمي (qc / 1642) لكنه غير معروض للمستخدم

## طريقة النشر على GitHub Pages
1. أنشئ repository جديد على GitHub (مثلا `returns-checker`)
2. ارفع كل محتويات هذا الفولدر (index.html)
3. اذهب إلى Settings > Pages
4. اختر Source: Deploy from a branch
5. اختر Branch: main / root
6. احفظ - سيظهر لك لينك مثل: https://USERNAME.github.io/returns-checker/
